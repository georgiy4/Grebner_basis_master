#Тема

Базисы Грёбнера в различных алгебрарических структурах

План:

ППС (27–31 января 2027 г.): обзор литературы по базисам Грёбнера–Ширшова, постановка задачи, выбор классов алгебраических структур.

КМУ (4–7 апреля 2027 г.): реализация и оптимизация алгоритма построения базиса, первые экспериментальные результаты.

Конф. по мат. моделированию (июнь 2027 г.): анализ эффективности предложенных модификаций, подготовка тезисов доклада.

Далее (2027–2028 гг.): оформление научной статьи, доработка алгоритмов, подготовка диссертации к защите.
